- **Native menus and image list**: the menu bar and the image list are now real Windows controls rather than WinForms-drawn imitations, which is what screen readers need from them ([#68](https://github.com/Oire/sic/issues/68)). The menu is a genuine `HMENU`, announced as a menu bar with real submenus; the image list is a genuine `SysListView32`, so a screen reader reads every column instead of only the file name. Nothing changes about how either looks or behaves for sighted users.
- SIC! can now be installed and updated through WinGet
